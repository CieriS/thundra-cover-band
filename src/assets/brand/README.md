# Logo della band

Metti qui il file ufficiale del logo con il nome `logo.svg` (oppure `logo.png`,
`logo.webp`, `logo.avif`). Alla build successiva compare da solo nell'hero,
nell'intestazione e nel footer.

Il logo si usa solo da questo file: non va ridisegnato né imitato in CSS o SVG.
Finché il file manca, il sito mostra il nome della band come semplice testo.

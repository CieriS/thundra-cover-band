# Logo della band

`logo-original.jpg` è il logo fornito dalla band (rosso pieno su fondo bianco).
`node scripts/build-logo.mjs` ne ricava `logo.png`, `logo-compact.png`, `bolt.png`, le icone e
l'anteprima dei link in `public/`.

Il logo si usa solo da questi file: non va ridisegnato né imitato in CSS o SVG.
